# dair emotion

**License**: Other (open academic)  
**Source**: DAIR.AI  
**HuggingFace**: https://huggingface.co/datasets/dair-ai/emotion  
**Total Rows**: 20,000  
**Columns**: text, label (6 basic emotions)  

## Description
English Twitter messages labeled with 6 basic emotion categories: joy, sadness, anger, fear, surprise, love. Compact, high-quality dataset for seeding core EmotionalState nodes.

## KG Layer Mapping (kg_guide_v2.pdf)
Layer 2 — Emotional States (6 basic: joy, sadness, anger, fear, surprise, love)
