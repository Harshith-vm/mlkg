## Description
Synthetic dataset based on CBT (Cognitive Behavioral Therapy) principles. Contains therapist-client dialogues demonstrating core CBT techniques such as thought records, cognitive restructuring, and behavioural experiments. Key source for TherapeuticTechnique nodes in Layer 5.
