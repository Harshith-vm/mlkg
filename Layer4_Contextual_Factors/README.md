# Layer 4: Contextual Factors

This layer contains environmental and contextual factors (e.g., Job Loss, Childbirth, Medical Diagnosis).

**Where is the data?**
To maintain 100% medical accuracy and avoid hallucination, Layer 4 does not rely on random internet NLP datasets. Instead, Contextual nodes are generated directly from authoritative medical text (DSM-5/ICD-11). 

The Cypher code that generates the Layer 4 Contexts is located inside the master graph generator scripts at:
`../Layer1_Clinical_Truth/cypher_scripts/`
