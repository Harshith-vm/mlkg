# Empathetic Dialogues Llm

**License**: Apache 2.0  
**Source**: Estwld (HuggingFace)  
**HuggingFace**: https://huggingface.co/datasets/Estwld/empathetic_dialogues_llm  
**Total Rows**: 24,850  

## Description
LLM-formatted version of empathetic dialogues dataset. Contains emotionally-aware conversations with 32 emotion labels covering the full spectrum of human emotional states. Instruction-tuning format (system/user/assistant). Maps directly to Layer 2 EmotionalState nodes.

## KG Layer Mapping (kg_guide_v2.pdf)
Layer 2 (EmotionalState — 32 emotion types) + Layer 6 (Session/Instance)
