# counsel chat

**License**: Apache 2.0  
**Source**: CounselChat (Bertagnolli)  
**HuggingFace**: https://huggingface.co/datasets/nbertagnolli/counsel-chat  
**Total Rows**: 2,775  
**Columns**: questionTitle, questionText, answerText, topic, therapistInfo  

## Description
Real counseling Q&A from licensed therapists scraped from CounselChat.com. Each answer is tagged with a counseling topic (e.g. anxiety, depression, relationships, grief). Topic tags map directly to KG Layer 4 context nodes and Layer 5 therapeutic technique nodes.

## KG Layer Mapping (kg_guide_v2.pdf)
Layer 5 + Layer 6 — Real therapist answers with topic tags
