**License**: CC BY-NC 4.0  
**Source**: Tsinghua University COAI Lab  
**HuggingFace**: https://huggingface.co/datasets/thu-coai/esconv  
**Total Rows**: 1,300  

## Description
1,300 emotional support conversations between supporters and seekers. Each conversation is annotated with: emotion category, problem type (relationship/work/school/family/etc.), and support strategy used (question, restatement, suggestion, affirmation, self-disclosure, etc.). The support strategies map directly to TherapeuticTechnique nodes in Layer 5.

## KG Layer Mapping (kg_guide_v2.pdf)
Layer 4 (ContextCategory) + Layer 5 (Therapeutic support strategies)
