# Layer 3: Behavioural Patterns

This layer contains behavioural patterns (e.g., Insomnia, Avoidance, Aggression).

**Where is the data?**
To maintain 100% medical accuracy and avoid hallucination, Layer 3 does not rely on random internet NLP datasets. Instead, Behaviour nodes are generated directly from authoritative medical text (DSM-5/ICD-11). 

The Cypher code that generates the Layer 3 Behaviours is located inside the master graph generator scripts at:
`../Layer1_Clinical_Truth/cypher_scripts/`
